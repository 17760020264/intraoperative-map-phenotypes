# Data Sharing Statement

The deidentified source data used in this study are available from the Medical Informatics Operating Room Vitals and Events Repository (MOVER; DOI: 10.24432/C5VS5G) and **INSPIRE version 1.0** (DOI: 10.13026/jyzb-ez61), subject to the respective repositories’ access requirements and data-use terms. Because the authors do not control redistribution rights, patient-level source data and derived operation-level analytic datasets are not redistributed. Versioned analysis code, the frozen 20-feature specification, MOVER scaling parameters, principal-component loadings, k-means centroids, synthetic example data, and nonidentifiable result summaries are available at **https://github.com/17760020264/intraoperative-map-phenotypes** and will be archived at **[INSERT ZENODO DOI]**. A bilingual research implementation of the frozen classifier is available at https://huggingface.co/spaces/1449648578Zyc/intraoperative-map-phenotype. The application is intended for research, education, and method reproduction; it is not a medical device or a source of treatment recommendations.
